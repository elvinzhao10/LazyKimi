# LazyKimi

[![Current release v1.4.1](https://img.shields.io/badge/release-1.4.1-0d9488)](https://github.com/elvinzhao10/LazyKimi/releases/latest)

**Plan, build, and verify in Kimi Code.**

Plan, execute, and verify coding work with persistent project context in Kimi Code.

- Editable plans and persistent project decisions.
- Focused execution with verification and evidence.
- Checkpoints and handoffs for ongoing work.
- A local dashboard for plans, progress, and package health.

## Get started

Use the [LazyKimi installation guide](https://github.com/elvinzhao10/LazyKimi/blob/main/docs/03-install-and-host-verification.md) for your app. Confirm the integration in a fresh session before starting project work.
